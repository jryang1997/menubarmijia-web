# MenuBarMijia 演示动图录制分镜表 (MEDIA_SHOTLIST)

> **文档定位：** 实机录屏执行指南  
> **适用版本：** MenuBarMijia `v1.1.4`  
> **核心原则：** 画面干净、节奏沉稳、动作真实、留足阅读停留。

## 录制通用参数建议

| 参数项 | 推荐值 | 说明 |
| :--- | :--- | :--- |
| **录制工具** | 系统自带 QuickTime / ScreenFlow / CleanShot X | 尽量选原生 2x Retina 录制，光标保持系统标准大小 |
| **系统外观** | macOS 浅色或深色（建议固定一套，壁纸使用干净纯色或自然风景） | 避免桌面堆满杂乱图标，隐藏 Dock 栏，清理无关联菜单栏图标 |
| **导出帧率** | 12 – 14 fps | GIF 画面平滑且体积可控，推荐用 `gifski` 或 `ffmpeg` 转码 |
| **首尾停留** | 开头留白 0.8s，结尾留白 1.5s | 避免循环播放时画面急促跳帧，给读者看清最终状态的时间 |

## 详细逐秒分镜脚本

### 【GIF-01】Hero 键盘搜索与极速控制（P0 · 首页主图）

* **目标：** 7 秒内证明“手不离键盘，打字找灯比掏手机更快”。
* **前置准备：**
  1. 准备一台受控灯（如台灯或吸顶灯，当前处于**关闭**状态）。
  2. 桌面清爽，MenuBarMijia 图标常驻菜单栏。

| 时间轴 | 你的操作（鼠标/键盘） | 屏幕画面与界面反馈 | 录屏字幕建议 |
| :---: | :--- | :--- | :--- |
| **0.0s – 0.8s** | 保持静止，不按键。 | 干净的桌面局部与顶部菜单栏，画面安静沉稳。 | （无字幕） |
| **0.8s – 1.6s** | 键盘按下全局快捷键 `⌥M`。 | 菜单栏下方平滑弹出控制面板，搜索框自动聚焦，光标闪烁。 | `⌥M 呼出` |
| **1.6s – 2.8s** | 连续敲入拼音字母 `sftd`（或对应设备拼音首字母）。 | 搜索框实时显示字符，列表即时过滤并高亮「书房台灯」，卡片呈聚焦选中态。 | `打字搜索` |
| **2.8s – 4.0s** | 键盘敲击回车键 `Return ↵`。 | 焦点设备瞬间开启，卡片高亮变色，菜单栏开启数/图标状态同步跳变。 | `回车开关` |
| **4.0s – 5.2s** | 键盘再次按下 `⌥M`（或按 `Esc`）。 | 面板平滑收起，视线重回清爽桌面。 | （无字幕） |
| **5.2s – 7.0s** | 桌面保持静止 1.8 秒。 | 菜单栏图标显示已开启状态，为循环留足阅读时间。 | （自然循环） |

### 【GIF-02】按住说话，松手执行与执行回执（P0）

* **目标：** 展现无唤醒词、像对讲机一样干脆的对谈体验，并带出 `⚡ 本地 · 12ms` 执行回执。
* **前置准备：** 设备（如台灯）当前处于开启的普通日光状态。

| 时间轴 | 你的操作（鼠标/键盘） | 屏幕画面与界面反馈 | 录屏字幕建议 |
| :---: | :--- | :--- | :--- |
| **0.0s – 1.0s** | 光标移至菜单栏图标，**按住鼠标左键不放**（或长按键盘 `⌥M` 0.2s 以上）。 | 面板弹出，顶部指令栏展开，麦克风波形指示器开始实时律动（监听中）。 | `按住说话` |
| **1.0s – 3.2s** | 对着麦克风自然说出：“**把书房灯切到月光模式**”。 | 指令输入框实时打字般浮现语音识别文字：“把书房灯切到月光模式”。 | （展示说话内容） |
| **3.2s – 4.2s** | **松开鼠标左键**（或松开键盘快捷键）。 | 监听瞬间停止，状态变为执行中。 | `松手即执行` |
| **4.2s – 6.2s** | 等待界面响应。 | 台灯卡片瞬间切入柔和月光模式，输入框右侧浮现绿色 `⚡ 本地 · 12ms` 回执胶囊。 | `秒级解析 · 零延迟` |
| **6.2s – 8.2s** | 保持面板展开静止 2 秒。 | 读者能清晰看清执行回执与设备状态变化。 | （静止停留） |

### 【GIF-04】Mac 屏幕状态与锁屏自动化联动（P1）

* **目标：** 展现 MenuBarMijia 融入 Mac 工作流的核心杀手锏（离席关设备）。
* **前置准备：**
  1. 在「设置 → 自动化」中配置好一条规则：「当离开 Mac（锁屏/休眠）时 ➔ 关闭书房台灯」。
  2. 书房台灯此时为**开启状态**。

| 时间轴 | 你的操作（鼠标/键盘） | 屏幕画面与界面反馈 | 录屏字幕建议 |
| :---: | :--- | :--- | :--- |
| **0.0s – 2.0s** | 设置窗口一闪展示配置规则后切到桌面。 | 规则明确标注“离开 Mac ➔ 关闭书房台灯”，设备灯正开着。 | `自设自动化规则` |
| **2.0s – 3.5s** | 点击左上角苹果菜单「锁定屏幕」（或按下快捷键 `^⌘Q`）。 | 屏幕平滑切至 macOS 原生锁屏大图壁纸，系统进入锁定状态。 | `锁屏离席` |
| **3.5s – 5.5s** | 敲击键盘或 Touch ID 快速解锁重返桌面。 | 屏幕唤醒解锁，重回桌面。 | `解锁重回桌面` |
| **5.5s – 7.5s** | 快捷键 `⌥M` 呼出控制面板。 | 面板展开：书房台灯已经处于**关闭状态**，底部显示锁屏执行成功记录。 | `台灯已随锁屏自动关闭` |
| **7.5s – 10.0s** | 保持面板静止停留 2.5 秒。 | 确认自动化真实生效。 | （自然循环） |

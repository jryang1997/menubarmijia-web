MenuBarMijia

在电脑上，顺手控制整个家。

面向 macOS 的原生菜单栏智能家居控制工具，亦提供 Windows 11 托盘版本。
无需提前搭建 Home Assistant，手机扫码即可连接米家；支持键盘拼音盲搜、按住说话、状态联动与误触撤销。

为什么把家居控制放进电脑

在电脑前工作或开会时，不必特意拿起手机打断手头的事：

  • 手不离键盘，打字找灯： 按下 ⌥M 呼出面板，输入名字或拼音首字母（如 sftd 找「书房台灯」），回车直接开关，左右方向键调节亮度与色温。不用切换中文输入法，不用在多层房间列表里滚动寻找。
  • 按住说话，松手执行： 长按全局快捷键 ⌥M 或菜单栏图标开始说话，说完松开立即执行。常规开关、调光、调温由本地规则秒级解析；多步或模糊指令可由你自选的 AI 处理，没有唤醒词，也不做多余的语音播报。
  • 跟上你的工作状态： 人离开 Mac 锁屏时自动关掉书房灯，接上外接显示器时打开桌面氛围灯。系统事件与家居控制的联动规则默认全部关闭，全凭你按需启用。
  • 能撤销，才敢放心批量关： 睡前长按 0.6 秒全关当前房间所有运行中的灯与温控设备。插座与扫地机默认排除，避免误切路由器电源；误触后底部提供 10–15 秒撤销横幅，点一下就能恢复原状。

功能概览与双端对照

MenuBarMijia 的 macOS 版本采用 Swift 6 原生开发，Windows 11 版本基于 Tauri v2 / TypeScript 独立实现。两端均经过共享测试集（Tests/Fixtures/）断言基础协议的一致性，但系统级能力存在平台差异。

快速开始

1. 系统要求与安装

  • macOS： 支持 macOS 14 (Sonoma) 及以上系统。
  • Windows： 支持 Windows 11（64 位）。

macOS 安装

方式 A：通过 Homebrew 一行安装（推荐）

brew install --cask jryang1997/tap/menubarmijia
若 Homebrew 提示需要信任第三方 Tap，可先执行 brew trust --cask jryang1997/tap/menubarmijia。

方式 B：下载 DMG 手动安装
前往 GitHub Releases 下载最新的 MenuBarMijia-1.1.4.dmg，打开并将 MenuBarMijia.app 拖入「应用程序（Applications）」文件夹。
首次打开拦截说明： 本项目为个人开源作品，尚未加入付费的 Apple 开发者计划（未完成 Developer ID 公证）。首次启动若被 Gatekeeper 拦截，请打开 「系统设置 → 隐私与安全性」，在页面底部点击针对 MenuBarMijia 的 「仍要打开」 即可。

Windows 11 安装

前往 GitHub Releases 下载 MenuBarMijia-1.1.4-windows-x64-setup.exe 或 .msi 安装包。
SmartScreen 提示说明： 当前 Windows 正式发布包暂未购买商业代码签名证书。首次安装若弹出“Windows 已保护你的电脑”，请点击 「更多信息」→「仍要运行」。安装包 SHA-256 哈希值已在 Releases 页面公开，可自行校验完整性。

  • 方式一：米家云端扫码直连（推荐）： 在设置中选择「米家云端直连」，屏幕上将显示登录二维码。使用手机「米家」App 扫码并确认登录，全屋家庭、房间与设备将自动同步到面板中。

安全、隐私与限制

  1. 非小米官方合作或客户端： 本项目是个人主导的独立开源工具，未获得小米、米家官方授权。云端直连使用非公开的米家客户端接口，小米可能随服务升级调整协议或触发账号风控。若对账号安全有顾虑，建议在 macOS 上使用基于官方开源集成的 Home Assistant 模式。
  2. 凭据安全与系统钥匙串：
    • macOS 端：登录会话令牌与配置的 AI API Key 统一保存于 macOS 系统钥匙串（CredentialVault），不留明文文件，且不再保存账号级长期 passToken`。由于使用自签名证书，升级版本后首次启动系统可能会询问一次钥匙串授权，点击「始终允许」即可。
    • Windows 端：登录凭证统一保存于 Windows 凭据管理器（Credential Manager），本地存储仅保留 UI 布局偏好。
  3. AI 服务的交互与数据边界： 使用本地解析口令时，没有任何数据会外发至第三方大模型服务。仅当你主动配置了外部 AI 服务（如 DeepSeek、OpenRouter 或自定义端点）且输入了复杂模糊指令时，应用才会把当句口令、当前涉及设备的状态摘要发往该端点。API Key 始终留在请求头中，绝不会拼接至 Prompt 正文，亦绝不包含米家登录凭据。
  4. 高风险操作二次确认： AI 模型给出的操作建议中，置信度低于 80% 的动作不会擅自运行，而是作为候选胶囊供你点选。对于电暖器开启、智能插座通电、启动扫地机等高风险动作，无论置信度多高，均必须经由人工二次确认。
  5. 设备通信路径与离线边界： 设备控制指令需经由米家云端或局域网 Home Assistant 转发到达设备。当前版本未提供全屋局域网 miIO 直连（技术论证详见 ADR-0007），在米家云模式下电脑需保持联网。
  6. 签名与公证说明： 本项目暂未购买付费的 Apple 开发者商业证书与 Windows Authenticode 签名。macOS DMG 的应用内更新采用内置 Ed25519 离线私钥做摘要防篡改校验；首次全新安装请参考前文的系统放行说明。

参与开发与技术架构

Why Put Smart Home Control on Your Desktop?

When coding, writing, or in a meeting, you don't need to reach for your phone:

  • Keep Your Hands on the Keyboard: Press ⌥M to summon the panel, type a name or pinyin initials (e.g. sftd for "Study Desk Lamp"), and hit Return to toggle. Use arrow keys to adjust brightness or color temperature. No scrolling through nested room trees.
  • Push-to-Talk, Release to Run: Hold ⌥M or the menu bar icon to speak your command, and release when you are done. Everyday commands like switching lights or setting the thermostat run instantly through local parsing rules—no wake words, no sluggish voice chatter. Optional AI backends handle multi-step requests.
  • Sync with Your Daily Work Rhythm: Automatically turn off lights when you lock your Mac or step away. Trigger your focus lighting when plugging in an external display. All automation rules are disabled by default; you stay in full control of what triggers when.
  • Peace of Mind with One-Click Undo: Long-press "All Off" for 0.6 seconds before bed to shut down active lights and climate devices in the current room. Crucial plugs and vacuum robots are excluded by default to protect network equipment. If you hit it by mistake, an undo banner floats for 10–15 seconds to restore your previous states and brightness values.
